Launch a Clinic Site

Four steps, about five minutes. Tick them off as you go — your progress is saved in this browser. New sites stay hidden from Google until you give them their real domain, so there is no rush to get the content perfect first.

Suggested repo name: tww-…

This copies the template into a new GitHub repo, creates a Netlify site, and deploys it. When Netlify asks for a repository name, use the suggested name above.

Deploy to Netlify
Give it a clinic-specific name. Every clinic needs its own repo — you can't reuse one.
It works like a staging site until you add the real domain. The site is reachable straight away on a temporary netlify.app address, but it is deliberately hidden from Google while it still has placeholder content. Adding the clinic's custom domain is what puts it into search results — no switch to flip.

This is what lets clinic staff log in and edit. Go to decapbridge.com and add a site:

GitHub repositoryjeff-cmyk/tww-…
Decap login URLhttps://your-site.netlify.app/admin/
GitHub tokenThe shared clinic token
Keep the trailing slash on the login URL, and use the repo's real Netlify address. If the clinic gets a custom domain later, come back and update this field or logins will break.

DecapBridge will show you URLs containing a long id, like /sites/f53ffc7a-…/pkce. Copy that id. Then in Netlify, on the new site, go to Site configuration → Environment variables and add:

KeyDECAP_SITE_ID
ValueThe id you just copied

Then redeploy — Deploys → Trigger deploy. Environment variables don't take effect until the next build.

How to check it worked: open your-site.netlify.app/admin/config.yml. If the top says “THIS CMS IS NOT CONFIGURED”, the variable didn't take or you haven't redeployed yet.

In DecapBridge, open the site and use Manage collaborators to invite staff by email. They sign in with a password, Google or Microsoft — no GitHub account needed.

  • Give clinic staff the Collaborator role — they can edit content and nothing else.
  • Only make someone an Admin if they should be able to add and remove their own colleagues.

Then send them their admin link: https://your-site.netlify.app/admin/

Do this last, once the content is filled in. Up to now the site has been reachable but hidden from Google — this is the step that puts it into search results.

  1. Add the domain in Netlify. Domain management → Add a domain. Then point the domain's DNS at Netlify from wherever it is registered. HTTPS is issued automatically once DNS resolves, which can take a few minutes.
  2. Redeploy the site. Deploys → Trigger deploy → Deploy site.
  3. Update the login URL in DecapBridge. The site's settings still point at the old netlify.app address.
The redeploy is not optional. Whether a site is visible to Google is decided when it builds, so adding the domain on its own changes nothing. Skip this and the clinic stays invisible in search with nothing appearing to be wrong. To check: open your-domain.com/robots.txt — if it says Disallow: /, it still needs a deploy.
Forgetting the DecapBridge URL breaks staff logins. They get sent to the old address instead of the site they are trying to edit.
If the clinic already has a website on that domain, changing the DNS takes the old one down as soon as it propagates. Treat that as a planned switchover: finish and check the new site on its netlify.app address first, agree a time with the clinic, and leave the old host running for a few days in case you need to go back.

Before it goes public

The site is live the moment it deploys, but it's full of placeholder text. These are the fields that cause real problems when they're missed.

FieldWhy it matters
Scheduling → NEO URLLeave it blank and every “Schedule Appointment” button quietly falls back to a phone link. Nothing errors — the buttons just stop reaching the booking system.
Address → Lat / LongDefaults to 0, 0, which is a real place in the Gulf of Guinea. It looks filled in but isn't. Get the real numbers from Google Maps — right-click the clinic's pin and the coordinates are at the top.
Hero → Background ImageAlso used as the preview image when the site is shared on social media.
HoursSplit days are fine — write them as 9:00am – 12:00pm & 2:00pm - 6:00pm and both blocks are published to Google.
Tracking → GA4 / PixelOptional. Left blank, no analytics tags are added at all.
Custom domainAdded in Netlify under Domain management. This is the step that makes the site public in search. Until it is set the site stays on its netlify.app address and is blocked from Google, so add it only once the content is filled in.

Adding video

The About section and each Service can take a video. Paste a Vimeo or YouTube link into the Video field — that's it.

  • The section's photo becomes the thumbnail, with a play button over it.
  • The video only loads when a visitor clicks it, so it doesn't slow the page down.
  • Video is deliberately not available on the homepage — that's the page that matters most for local search rankings.
